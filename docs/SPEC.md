## 1. ภาพรวม

| หัวข้อ | รายละเอียด |
|---|---|
| ผู้ใช้หลัก | พนักงานหน้าร้าน, สัตวแพทย์, เจ้าของร้าน |
| รูปแบบโปรแกรม | โปรแกรม Windows ติดตั้งในเครื่องของร้าน (.exe) |
| ฐานข้อมูล | ในเครื่อง (SQLite) — ใช้งานได้แม้อินเทอร์เน็ตล่ม |
| ดูข้อมูลออนไลน์ | Sync ขึ้น Cloud (Supabase) → ดูแบบ Real Time ผ่านเว็บจากมือถือ/คอมเครื่องอื่น |
| การอัปเดต | Auto-update — ผู้พัฒนาออกเวอร์ชันใหม่ เครื่องร้านอัปเดตเอง |
| ภาษา | ไทย |

### สถาปัตยกรรม

```
[เครื่องหน้าร้าน]                         [Cloud]                 [อุปกรณ์อื่น]
Electron + React (Windows)                                       มือถือ / แท็บเล็ต / คอม
└─ SQLite (ข้อมูลหลัก)   ── sync ──▶   Supabase Postgres  ── Realtime ──▶  เว็บดูข้อมูล (ต้อง login)
```

### เทคโนโลยี

- **Desktop:** Electron + React + TypeScript
- **ฐานข้อมูลในเครื่อง:** SQLite
- **Cloud / Realtime / Login:** Supabase
- **เว็บดูออนไลน์:** React (ใช้ component ร่วมกับ Desktop)
- **ไฟล์ติดตั้ง + อัปเดต:** electron-builder + auto-update

## 4. รายการฟีเจอร์ทั้งหมด

สัญลักษณ์เฟส: **[1]** MVP · **[2]** เฟส 2 · **[3]** เฟส 3

### 4.1 ลูกค้าและสัตว์เลี้ยง
- [1] เจ้าของ 1 คน มีสัตว์ได้หลายตัว, ประวัติแยกรายตัว
- [1] ข้อมูลสัตว์: ชนิด, พันธุ์, เพศ, วันเกิด, สี, น้ำหนัก, ทำหมัน, ไมโครชิป, รูป
- [1] ค้นหาจากชื่อสัตว์ / ชื่อเจ้าของ / เบอร์โทร
- [1] ป้ายเตือน: แพ้ยา, ดุ/กัด
- [1] ความยินยอม PDPA ของเจ้าของ
- [2] นำเข้าข้อมูลจาก Excel

### 4.2 เวชระเบียน (EMR)
- [1] บันทึกการตรวจแบบ SOAP
- [1] น้ำหนัก / อุณหภูมิ / สัญญาณชีพ
- [2] กราฟน้ำหนักย้อนหลัง
- [2] แนบรูป / ผล Lab / X-ray
- [2] เทมเพลตอาการที่พบบ่อย

### 4.3 วัคซีนและการป้องกัน
- [1] สมุดวัคซีนดิจิทัล (พิษสุนัขบ้า, รวม 5 โรค, รวม 4 โรค ฯลฯ)
- [1] ถ่ายพยาธิ, ป้องกันเห็บหมัด/พยาธิหนอนหัวใจ
- [1] คำนวณวันนัดครั้งถัดไปอัตโนมัติตามรอบที่ตั้งไว้

### 4.4 นัดหมายและคิว
- [1] รายการสัตว์ที่ครบกำหนดนัด (วัคซีน/ตรวจซ้ำ)
- [2] ปฏิทินนัด รายวัน/สัปดาห์ แยกตามหมอ
- [2] คิวหน้าร้าน: รอตรวจ → กำลังตรวจ → รอจ่ายเงิน → เสร็จ
- [2] แจ้งเตือนนัดผ่าน LINE

### 4.5 คลังยาและสินค้า
- [1] ตัดสต็อกอัตโนมัติเมื่อจ่ายยา/ขาย
- [1] รับของเข้า, ต้นทุนเฉลี่ยถ่วงน้ำหนัก
- [1] เตือนของใกล้หมด
- [2] ผู้จำหน่าย, ใบสั่งซื้อ
- [2] นับสต็อก, ตัดของเสีย/หาย/หมดอายุ
- [3] Lot / วันหมดอายุ / จ่ายแบบ FEFO, เตือนใกล้หมดอายุ
- [3] ทะเบียนยาควบคุมพิเศษ

### 4.6 เอกสารและการพิมพ์
- [1] ใบเสร็จรับเงิน
- [2] ฉลากยา, ใบนัด
- [2] ใบรับรองสุขภาพ, ใบรับรองวัคซีนพิษสุนัขบ้า
- [2] ใบยินยอมผ่าตัด/วางยาสลบ

### 4.7 บริการเสริม (รอยืนยันว่าร้านมีหรือไม่)
- [3] ฝากเลี้ยง: จองกรง, เช็คอิน/เอาท์, คิดค่าบริการรายวัน, มัดจำ
- [3] อาบน้ำตัดขน: คิว + ราคาแยก
- [3] สัตว์ป่วยใน (IPD): บันทึกให้ยา/อาการรายวัน

## 5. โมดูลการเงิน 💰 (เน้นพิเศษ)

### 5.1 ราคาและการขาย
- [1] บิลเดียวรวม ค่าตรวจ + หัตถการ + ยา + สินค้า
- [1] ทุกรายการบริการระบุ **หมอผู้ทำ** (สำหรับ DF)
- [2] ใบเสนอราคา / ประเมินค่าใช้จ่าย (ช่วงราคา) → แปลงเป็นบิล
- [2] ค่าบริการแบบชุด (เช่น ทำหมัน = ยาสลบ + ยา + ค่าผ่าตัด) ตัดสต็อกในชุดอัตโนมัติ
- [3] ราคาหลายระดับ (ปกติ / สมาชิก)
- [3] แพ็กเกจซื้อล่วงหน้า ตัดใช้ทีละครั้ง

### 5.2 รับชำระเงิน
- [1] เงินสด / โอน / QR PromptPay / บัตร
- [1] แบ่งจ่ายหลายช่องทางในบิลเดียว
- [1] มัดจำ → หักตอนจ่ายจริง
- [1] ค้างชำระ (แบบเรียบง่าย): สถานะบิล, ยอดค้างเด่นในหน้าลูกค้า, รับชำระเป็นงวด
- [2] เครดิตคงเหลือในบัญชีลูกค้า

### 5.3 ส่วนลด คืนเงิน และการกันทุจริต
- [1] เพดานส่วนลดตามสิทธิ์ผู้ใช้ — เกินต้องให้ผู้มีสิทธิ์อนุมัติ
- [1] ยกเลิกบิล/คืนเงิน ต้องระบุเหตุผล + รหัสผู้อนุมัติ, ไม่ลบบิลจริง (ทำใบลดหนี้/สถานะยกเลิก)
- [1] เลขที่บิลรันต่อเนื่อง ห้ามข้าม/แก้ไข
- [1] Log การแก้ราคา / ส่วนลด / ยกเลิก

### 5.4 ลิ้นชักเงินสดและปิดกะ
- [1] เปิดกะ: เงินทอนตั้งต้น
- [1] ปิดกะ: ยอดที่ควรมี vs นับจริง → ส่วนต่างขาด/เกิน
- [1] สรุปแยกช่องทาง (เงินสด / โอน / บัตร)
- [2] เงินสดย่อย (Petty cash)

### 5.5 ต้นทุนและกำไร
- [1] ต้นทุนเฉลี่ยถ่วงน้ำหนัก
- [2] กำไรขั้นต้น ต่อบิล / ต่อสินค้า / ต่อบริการ

### 5.6 ค่าใช้จ่ายและเจ้าหนี้
- [2] บันทึกค่าใช้จ่ายร้านแยกหมวด (ค่าเช่า, ไฟ, เงินเดือน, แล็บภายนอก)
- [3] เจ้าหนี้ผู้จำหน่าย + เตือนครบกำหนดจ่าย

### 5.7 ค่าดำเนินการแพทย์ (DF) และคอมมิชชั่น
- [1] เก็บข้อมูลหมอผู้ทำในทุกรายการบริการ (ต้องมีตั้งแต่บิลแรก)
- [2] ตั้งอัตรา DF รายบริการ / รายหมอ — **รูปแบบรอยืนยันกับร้าน**
- [2] รายงาน DF รายวัน/รายเดือนแยกหมอ
- [3] คอมมิชชั่นพนักงาน (ขายสินค้า / Grooming)

### 5.8 ภาษี (VAT)
- [1] สวิตช์ VAT ในตั้งค่า (ปิดไว้ก่อน), ตั้งสถานะ VAT รายสินค้า/บริการ, ราคารวม/ไม่รวม VAT
- [1] ปิด VAT → ออกใบเสร็จรับเงิน
- [2] เปิด VAT → ใบกำกับภาษีอย่างย่อ/เต็มรูป, ใบลดหนี้, เลขผู้เสียภาษี + วันที่เริ่มจด
- [2] ส่งออกข้อมูลให้นักบัญชี (Excel / FlowAccount / Express)
- [3] รายงานภาษีขาย/ภาษีซื้อ (ภ.พ.30)
- [3] e-Tax Invoice & e-Receipt
- ⚠️ ค่ารักษาสัตว์ต้องคิด VAT หรือได้รับยกเว้น — **ต้องถามนักบัญชี**

### 5.9 รายงานการเงิน
- [1] Dashboard วันนี้: ยอดขาย, จำนวนบิล, เงินสดในลิ้นชัก, ยอดค้างชำระ (ดูออนไลน์ได้)
- [1] ยอดขายรายวัน/เดือน แยกหมวด (ตรวจรักษา / ยา / อาหาร / สินค้า)
- [2] งบกำไรขาดทุนอย่างง่ายรายเดือน
- [2] เปรียบเทียบเดือนต่อเดือน / ปีต่อปี
- [2] รายได้แยกตามหมอ, สินค้าขายดี, มูลค่าสต็อกคงเหลือ
- [2] ส่งออก Excel
